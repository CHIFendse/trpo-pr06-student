# Практическая работа №06: PHP. Работа с файлами, JSON, сессиями и подготовка к MVC

## Описание проекта
Учебное PHP-приложение для управления списком заметок. Реализует долговременное хранение записей в формате JSON, изоляцию состояния пользователей с помощью сессий (`$_SESSION`), обработку форм по паттерну Post/Redirect/Get (PRG) и физическое разделение логики обработки запросов и представлений.
